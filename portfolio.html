Portfolio

Daniel Kamau studies software engineering at Zetech University in Kenya. He works across full-stack development and also handles hardware fixes plus network setup, which seems to fit together well for him.

His coding covers webpages that respond well using basic HTML, CSS, and JavaScript, along with Visual Basic .NET for desktop tools. Database work with SQL also comes up, and he uses Docker and Git to keep things organized in Visual Studio Code or on GitHub. There are some web apps built for local real estate needs in Kenya and a few custom desktop programs for management tasks.

It feels like problem-solving runs through most of what he does, but not always in a straight line. Hardware comes next with repairs on laptops and desktops, along with upgrades and full PC builds focused on keeping temperatures low. Operating systems are installed on both Windows and Linux, PowerShell helps with command work, and malware gets cleaned while drivers are added in.

Networking fits in with Cisco Packet Tracer practice and some CCNA basics. Local area networks are designed with routers and switches configured through the command line, and IP addressing and subnetting are handled for security reasons. I think the whole stack—from code to physical parts to connections—is what stands out, although some parts get messy when trying to separate them. One area that still blends in is how support flows from hardware checks straight into network configurations without much pause.
